AutoApply Demo Pages

Simulated job application pages for testing the AutoApply extension. Open a page, click the AutoApply icon, and hit Fill this page.

  • Greenhouse-style — label[for] fields, hidden file input, radio + select, open cover-letter question.
  • Lever-style — card layout, many selects/radios, salary and voluntary self-ID fields the extension should skip.
  • Workday-style — SPA look, blur validation, and a custom uploader that rejects automated file attach (amber highlight).
  • ARIA-only form — no label[for]; labels via aria-labelledby, aria-label, placeholder, and nearby text.
  • Multi-step wizard — three steps; one fill per step.
  • Iframe-embedded form — job posting in the top frame, form in an iframe.
